# LOWeather app

## Intended Use
 - At a glance the user will see the current weather conditions and wave conditions on Lake of the Woods
 - Also the user will be able to see the past 5 days of precipitation


## Locations
 - The wave buoy is located in the middle of Big Traverse Bay on Lake of the Woods and it is in a fixed location that cannot be changed
 - Updated: there will be no location selection. The only location will be Wheeler's Point.


## End goals
 - This app will be hosted on a web server and accessible to select users
 - The interface will be very minimal with likely no selections or options
 - The user will be visiting this web app from their mobile device
 - The user will be looking at this for informational purposes only
 - 

 ## Visuals
 - The app will have a simple, minimalistic design with no complex visuals or graphics
 - I want the visuals to be dynamic because the provided weather data parameters might change frequently
